# Log Electric Desk แผนทีละเฟส (เริ่ม 29/10/2026)

โจทย์พี่ปอนด์: แอป model driven บน Dataverse (ติดตั้งจริงที่ env Production ทรู) ให้ลูกทีมกรอก LOG ELECTRIC ตามเทมเพลต
ไฟล์ต้นแบบ `WEBAPP-LOG ELECTRIC.xlsx` ชีต WEBAPP-LOG ELECTRIC (แถว 1 = ประเภทช่อง, แถว 2 = หัวคอลัมน์, แถว 3 = ชนิดข้อมูล, แถว 4 ขึ้นไป = ตัวเลือก dropdown)

ท่าเดียวกับ Pending VAT Desk: web resource HTML ฝังในแอป ใช้ Xrm.WebApi ไม่พึ่ง flow (ทรูไม่มี premium)
พัฒนาและเทสที่ env ของเรา `https://pvdesk.crm5.dynamics.com` solution ใหม่ `LogElectricDesk` prefix `le` แล้วส่งซิป managed ให้พี่ติดตั้งที่ทรู

## เฟส

| เฟส | งาน | ตรวจยังไง |
|---|---|---|
| 1 | publisher, solution, ตาราง `le_logelectric` (ตารางเดียวที่ Power BI ใช้) กับ `le_history` | อ่าน metadata กลับมาครบทุกคอลัมน์ |
| 2 | บทบาท 3 ตัว LE Member (เห็นแถวตัวเอง), LE Manager (เห็นทุกแถว), LE Admin (ลบได้ทั้งหมด) | ผู้ใช้ทดสอบ 3 บทบาทยิงอ่านจริง |
| 3 | หน้าเว็บตาราง: INDEX, Created On/By, Modified On/By, ตัวกรองแบบ Excel, Group by, เพิ่มและแก้แถว | Playwright บน pvdesk |
| 4 | เทมเพลต (เฉพาะช่องที่ต้องกรอก มี dropdown), นำเข้าไฟล์, ไฟล์ error บอกแถวและคอลัมน์ | ไฟล์ผิดตั้งใจ แดงก่อน |
| 5 | ส่งออก CSV และ XLSX แบบติ๊กเลือก ตามตัวกรอง (Member ได้แค่แถวตัวเอง) | เทียบจำนวนแถวกับตัวกรอง |
| 6 | ประวัติการเปลี่ยนแปลงต่อแถว (ค่าเดิมเป็นค่าใหม่ ใครแก้ เมื่อไหร่) | แก้แถวแล้วดูประวัติ |
| 7 | หน้า Dashboard สำหรับ Manager, ปุ่มลบทั้งหมดของ Admin | ภาพจริง |
| 8 | แพ็กซิป managed, คู่มือติดตั้งที่ทรู, วิธีต่อ Power BI | import ซิปลง env สะอาด |

## ข้อตัดสินที่ฟ้าเลือกไว้ก่อน (พี่เปลี่ยนได้)

1. ไฟล์นำเข้ามีแถวผิดแม้แถวเดียว ไม่รับทั้งไฟล์ ส่งไฟล์ error กลับ (กันข้อมูลเข้าครึ่ง ๆ)
2. Member สร้างและแก้แถวตัวเองได้ ลบไม่ได้, Manager อ่านและแก้ได้ทุกแถว ลบไม่ได้, Admin ทำได้ทุกอย่างรวมลบทั้งหมด
3. dropdown เก็บเป็นข้อความตัวใหญ่ตามเทมเพลต (Power BI ใช้ตรงได้ ไม่ต้องแปลงรหัส)
4. SITE CODE NO CANDIDATE ระบบตัดจาก SITE CODE CANDIDATE ด้วยกฎเดียวกับ fnExtractSite (port จาก Pending VAT Desk)
5. COMPANY NAME ระบบเติมจาก COMPANY CODE
6. INDEX ใช้ autonumber ของ Dataverse เลขไม่ซ้ำ ลบแถวแล้วเลขไม่ถูกใช้ซ้ำ
7. ประวัติ: แอปเขียนแถวประวัติพร้อมการแก้ในคำสั่งเดียวกัน (สำเร็จหรือล้มพร้อมกัน) และเปิด audit ของตารางไว้ด้วย
8. ข้อมูลเก่า 30,417 แถวในตาราง `cr802_logelecric` ยังไม่ย้าย (ไม่มี PRO NUMBER กับ SITE CODE ที่ตอนนี้บังคับ)
